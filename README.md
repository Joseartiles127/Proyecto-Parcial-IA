# Proyecto-parcial-IA

## Jose Alberto Artiles

## 23-MISN-2-013

##  Descripción del Proyecto

Este proyecto consiste en el desarrollo de un videojuego basado en el clásico **Zombies Ate My Neighbours**, como parte del proyecto parcial de la materia Inteligencia Artificial. El objetivo principal es aplicar técnicas de IA básicas para controlar el comportamiento de los enemigos (zombies), detectar colisiones, navegación de los personajes, y crear una jugabilidad dinámica y entretenida.


## Inteligencia Artificial Aplicada

- **IA básica para enemigos:** Movimiento automático hacia el jugador.
- **Árbol de decisión simple** para cambiar comportamiento (perseguir, patrullar).
- **Colisiones inteligentes** con obstáculos.
- **Recolección de puntos de vida y armas.**
